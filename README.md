# Retro Edit

Retro Edit replaces the Geometry Dash editor object palette with the palette
from a selected version of the game, from 1.0 through 1.9.

<img src="logo.png" width="150" alt="the mod's logo" />

## Build instructions

Install the current Geode CLI and the Geode 5.10.1 SDK with its prebuilt
binaries, then run:

```sh
geode build
```

The project targets Geometry Dash 2.2081 and Geode 5.10.1 on Windows,
macOS, iOS, and 32/64-bit Android.
